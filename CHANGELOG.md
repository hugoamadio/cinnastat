# Changelog

## 0.1.0 (unreleased)

First version.

- 2×2 display with CPU, memory, disk and network, each over a history graph.
- Tooltip with load average, memory and swap in GB, disk read/write and free space, network down/up.
- Click opens System Monitor (configurable).
- Settings for update interval, width, colors and click command.
- Counts physical disks and network cards only, so Docker, VPN and LVM traffic is not counted twice.
